# ♠️ 牌局记分 (Score Tracker) 🀄

这是一个简洁、高效的纯前端牌局记分器，专为麻将、扑克等多人桌游场景设计。支持 **2-8人** 自由组局，无需注册，数据完全保存在您的浏览器本地，断网亦可正常使用。

 **在线访问地址**：[https://score.papership.top](https://score.papership.top)

---

## 🚀 使用方法

### 第一步：创建房间
1. 打开网页，选择本局参与的**玩家人数**（2 - 8人），点击 **下一步**。
2. 依次输入每位玩家的**昵称**，点击 **开始记分**。

### 第二步：积分流转
1. 牌局结束时，在界面上点击**输分（出分）**的玩家卡片，卡片边框会变为黄色。
2. 接着点击**赢分（收分）**的玩家卡片。
3. 在弹出的金额窗口中输入**转账分值**，点击 **确认** 即可完成。

### 第三步：查阅历史
* 页面底部的 **“积分记录”** 会实时展示积分变动明细。
* 即使在打牌过程中刷新了网页，数据依然会完好无损。

### 第四步：重新开局 / 换人
* 点击页面右上角的 **“重置”** 按钮：
  * 选择 **“重置分数”**：清除所有流水和积分（归零），原班人马直接开始新的一局。
  * 选择 **“重置房间”**：彻底清空数据，返回到选择人数的第一步。

## ✨ 功能特点

* **零后台依赖**：纯 HTML + CSS + JavaScript 编写，数据存储于浏览器的 `localStorage` 中，刷新或关闭网页后进度不丢失。
* **灵活的多人支持**：支持 2 到 8 人任意组局，自由填写玩家昵称。
* **极简的转分交互**：依次点击 **“出分人卡片” ➔ “收分人卡片”**，即可弹出金额框快速完成积分流转。
* **大赢家高亮**：系统动态计算全场积分最高者，并在其卡片右上角戴上专属皇冠 `👑`。
* **智能账目合并**：自动将 1 分钟内发生的多笔流水归为一组展示，并保留每个阶段的历史分数快照，查账对账更清晰。
* **多档重置选项**：支持“仅清空当前分数（保留玩家信息）”或“彻底重置房间（重新开始）”双重模式。
* **响应式设计**：完美适配手机端，方便在牌桌上单手点按操作。

## 🛠️ 技术栈
* **前端骨架**：HTML5
* **视觉样式**：CSS3 (支持移动端弹性盒与网格响应式布局)
* **交互逻辑**：原生 JavaScript (无任何外部框架依赖)
* **本地存储**：Web Storage API (localStorage)
