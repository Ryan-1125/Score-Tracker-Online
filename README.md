# 牌局记分

原生 JavaScript 页面 + Node.js / Socket.IO + SQLite。支持 2–8 人单机记分，以及房间联机同步。

## 本地运行

```sh
npm ci
npm start
```

浏览器打开 http://localhost:3000。同一局的其他设备通过服务器的局域网地址访问，再输入 4 位房间码加入。公网联机需要部署 Node 服务；静态网站仅支持本地模式。

```sh
npm test
```

测试使用内存数据库，不修改 data/rooms.db。联机测试需要允许访问本机端口。

## 已支持

- 本地单页设置：默认两人，可增删至八人，空昵称自动使用玩家序号；自动保存、刷新恢复、转分记录。
- 联机创建 / 加入房间，最多 8 位玩家，服务端保存分数。
- 刷新及断线重连保留稳定席位，通过设备保存的随机会话凭证恢复；不同标签页可独立组局。
- 房主可以代记；普通玩家只能从自己转出积分。支持选图案头像，进房后可修改头像昵称。
- 正整数积分校验、撤销最近一笔（联机限房主）、结算 PNG 图片导出。
- 排行榜与积分结算建议；所有成员可查看结算、导出图片，查看不会清除记录。
- 在线状态、房主移交、主动退出、恢复席位、复制房间号、房主解散。
- 服务端校验权限，最近记分请求去重，客户端显示等待确认。
- 深浅主题、掷骰子、移动端布局。

昵称只是显示名，不是身份凭证。请保留原设备的浏览器数据；清理浏览器数据后无法凭昵称恢复原席位。新标签页可用不同昵称加入，也可明确选择“恢复席位”找回原玩家。

## 代码入口

- score-core.js：无 DOM / 网络依赖的计分与结算规则，单机、服务端共用。
- script.js：页面交互、本地存储、Socket.IO 通信。
- server.js：房间身份、权限、校验、持久化与广播；只提供公开静态资源。
- test/：规则与联机集成测试。
- docs/PROJECT-NOTES.md：项目复盘与后续路线。
- docs/ONLINE-TESTING.md：电脑双标签页、手机局域网联机测试指南。

## 当前边界

这是第一轮基础完善，尚未完成生产上线。房间目前持续保存，未实现过期清理、踢人、牌局归档、限流和账号体系。旧房间按需兼容升级；没有凭证的旧席位不能安全恢复。单机数据保存在当前浏览器，结算图片用于分享结果，不能恢复完整流水；暂未提供数据备份导入。打开页面后的单机计分无需网络；尚未实现 PWA 离线启动。

微信小程序需要另建小程序页面，并接入登录身份、HTTPS / WSS 与合法域名配置，不能直接把当前 HTML 当作小程序发布。
